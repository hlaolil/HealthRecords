{# NEW: every item is listed up front, the way a paper count sheet works — walk the shelves, fill in what you find, post whatever you have done. Blank rows are ignored, so a sheet can be posted as many times as you like and the remaining items simply stay on it. The system balance is still absent: the count has to be blind. #}

Each row shows what the system has. Where the shelf matches, tick Agrees. Where it doesn't, type what you actually counted. The expiry and batch boxes already hold what is on file, so change them only if the pack says something different. Press Post Counts whenever you like: rows you haven't touched stay on the sheet, and rows you've posted drop off.

A tick is recorded as confirmed, not as a figure you counted, so the register shows which items were checked against the system and which were counted outright. If you tick a row and also type a count, the count is the one that is recorded. For controlled drugs, counting is safer than ticking.
