Opening Stock (optional)

Only for stock already on the shelf when this item is first set up — typically at go-live, where there is no invoice to receive it against. Leave the balance at 0 for a new item whose stock will arrive on a delivery. An opening load is recorded as exactly that, so it is never mistaken for a supplier delivery or a stock-take correction.
